# Gin Rummy Web Client

This is a React + TypeScript web client for the Gin Rummy game, scaffolded with Vite.

## Getting Started

### Prerequisites

- Node.js 18+

### Project Structure

- `src/main.tsx`: Application entry point.
- `src/App.tsx`: Root React component.
- `vite.config.ts`: Vite build/dev server configuration.
- `tsconfig.json`, `tsconfig.app.json`, `tsconfig.node.json`: TypeScript configuration.

### Available Scripts

- `npm run dev`: Starts the Vite development server with HMR.
- `npm run build`: Type-checks and bundles the app for production into `dist/`.
- `npm run preview`: Serves the production build locally.
- `npm run lint`: Lints the source code with Oxlint.

## Architecture

This client uses:

- **React**: UI library for building the interface.
- **Vite**: Fast dev server and build tool.
- **TypeScript**: For type-safe development.
